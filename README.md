# DEWED storefront (HTML/CSS/vanilla JS)
Open `index.html` with VS Code Live Server (needed for video and localStorage).
- Hero video: `assets/hero/dewed-hero.mp4`; editorial video: `assets/hero/dewed-editorial.mp4`
- Products: edit rows in `js/products.js`. Add real photos by placing files in `assets/products/` and swapping `art(p)` in `js/main.js`.
- Announcement text, logo path, shipping rules: top of `js/main.js`.
- Prices are indicative placeholders, not verified against any live site.
- Not built (needs backend): checkout/payment, accounts, real orders, real reviews. Sample reviews are fictional.
